# Illustration Composer

Плагин Figma Design для сборки сцен из существующих компонентов. Первая версия ищет компоненты по именам на текущей странице и автоматически размещает экземпляры в редактируемом фрейме.

## Запуск

1. Откройте редактируемый файл Figma Design в настольном клиенте.
2. Выберите **Plugins → Development → Import plugin from manifest…** и укажите `manifest.json` из этой папки.
3. Создайте на текущей странице несколько компонентов с уникальными именами или используйте существующие.
4. Запустите **Plugins → Development → Illustration Composer**. Введите имена компонентов, выберите формат и нажмите **Собрать композицию**.
5. Отредактируйте сцену инструментами Figma. Выделите фрейм композиции, нажмите **Подготовить SVG выбранного фрейма**, затем **Скачать SVG**.

Зависимости и сборка не требуются. ID в манифесте предназначен для локальной разработки. Перед публикацией используйте ID, выданный Figma.

## Структура

- `manifest.json` описывает точку входа и настройки плагина.
- `code.js` ищет компоненты, размещает экземпляры и вызывает экспорт SVG.
- `ui.html` содержит форму и скачивает готовый SVG.

В следующих итерациях предстоит подключить исходную библиотеку, добавить выбор компонентов по метафоре и импорт цветовых палитр.
