# Illustration Composer

Плагин Figma на Vue и TypeScript. Собирает редактируемые композиции из SVG по заголовку или метафоре.

## Запуск

В папке проекта с Node.js 22.12+ выполните:

```sh
npm ci
npm run build
```

В настольной Figma откройте любой файл и выберите **Plugins → Development → Import plugin from manifest…**. Укажите корневой `manifest.json`. Сборка помещает интерфейс и код плагина в `dist`.

## Разделы

- **Создать.** Введите запрос, укажите API-ключ TKBK для Claude, выберите палитру и размер холста. Доступны S (500 × 500), L (1000 × 1000) и **Свой размер** с шириной и высотой в пикселях. Нажмите **Создать**. Для проверки можно взять «Знания освещают путь», «Рост сбережений» или «Музыка объединяет». Первый фоновый цвет палитры заполняет весь фрейм. Слои на холсте можно перемещать и редактировать. Кнопка экспорта подготавливает SVG выбранного фрейма.
- **Библиотека.** Единый каталог содержит 20 SVG из предоставленного Untitled.fig. Для каждого объекта используется детализированный вариант из набора L, отдельно для основной и фоновой роли. Собственные векторные SVG до 250 КБ на файл доступны для любого размера холста. Файлы с растровыми вставками или внешними ссылками отклоняются.
- **Палитры.** Три встроенные схемы и редактор новых. Четыре фоновых и четыре основных цвета соответствуют позициям в исходной таблице. Фоновые объекты перекрашиваются по фоновым позициям. Дополнительные оттенки из исходника сохраняются. В пользовательских SVG замена применяется к сплошным цветам, которые совпадают с базовой палитрой.

## Подбор и данные

Метафору разбирает Claude Sonnet 5 через TKBK. Плагин отправляет текст запроса, размеры холста и списки основных и фоновых объектов с номерами и названиями. Модель выбирает основной объект и до двух дополнительных. При повторе той же метафоры плагин предлагает модели другой подход и передаёт предыдущий подбор. В карточке загруженного SVG можно менять его роль. Фоновые пользовательские SVG перекрашиваются в фоновые цвета выбранной палитры.

Шесть схем из референса служат основой для вариантов размещения. При каждой генерации меняются позиции и общий масштаб объектов. SVG могут частично выходить за край фрейма. Фрейм обрезает выступающие части при показе и экспорте, а слои остаются редактируемыми. Векторные фоны с линиями или диагональю взяты из исходного файла и перекрашиваются вместе с композицией.

Кнопка **Запомнить ключ** сохраняет API-ключ в локальном хранилище плагина Figma. При следующем запуске поле заполнится автоматически. Кнопка **Забыть ключ** удаляет сохранённый ключ. Без сохранения введённый ключ используется до закрытия окна. Локальное хранилище Figma не является зашифрованным хранилищем секретов.

Загруженные SVG и пользовательские палитры сохраняются локально через Figma clientStorage. Встроенные SVG экспортированы из исходного файла через refig и входят в сборку, поэтому исходный документ для запуска не нужен.
